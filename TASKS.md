# Tasks

Every `- [ ]` anywhere in the vault gathers here. Write them in your daily note, read them
here, and nothing gets lost in a note you forgot you opened.

## Due or overdue

```tasks
not done
due before in 7 days
sort by due
hide task count
```

## Everything open

```tasks
not done
sort by due
group by path
hide task count
```

## Done in the last 7 days

```tasks
done after 7 days ago
sort by done reverse
hide task count
```
